Oui. Et cette précision est importante : **l’image que nous avons travaillée doit être considérée comme un écran d’introduction / Hero immersif de la page d’accueil, et non comme toute la page d’accueil**.

Voici donc un **PRD complet et directement exploitable dans Antigravity** pour construire le site de l’ONG **ACT’ERE**.

# PRD — Site web ONG ACT’ERE

## 1. Présentation du projet

### Nom du projet

**ONG ACT’ERE**

### Type de site

Site institutionnel moderne pour une ONG engagée dans :

* les énergies renouvelables ;
* la protection de l’environnement ;
* l’éco-citoyenneté ;
* la sensibilisation environnementale ;
* les actions communautaires ;
* les projets de développement durable.

### Objectif principal

Créer un site web **moderne, immersif, professionnel et crédible**, permettant à l’ONG de :

1. présenter son identité ;
2. expliquer ses actions ;
3. présenter ses projets ;
4. sensibiliser les visiteurs ;
5. présenter son équipe ;
6. permettre aux visiteurs de contacter l’ONG ;
7. encourager l’engagement et la participation aux actions.

Le site doit donner une impression de **nature, action, engagement et modernité**.

---

# 2. Direction artistique

## Identité visuelle

L'identité visuelle doit reprendre la direction de la maquette fournie.

### Ambiance

**Nature + technologie + engagement citoyen.**

Le site doit éviter l'aspect :

* trop administratif ;
* trop scolaire ;
* trop chargé ;
* trop enfantin.

On recherche plutôt une esthétique de **ONG internationale moderne**.

### Couleurs principales

| Couleur                 | Utilisation                           |
| ----------------------- | ------------------------------------- |
| Vert naturel            | Actions, boutons, éléments importants |
| Vert foncé              | Navigation, fonds, textes             |
| Blanc                   | Titres et textes sur images           |
| Noir / vert très sombre | Contrastes                            |
| Beige très léger        | Sections claires                      |

Le vert doit rappeler :

**forêt → nature → énergie → renouvellement → action.**

---

# 4. Header / Navigation

Le header doit reprendre l'esprit de la maquette actuelle.

**ONG ACT’ERE**

### Navigation

# 5. HERO — Écran d'introduction

La création que nous avons réalisée correspond **uniquement à cette section**.

Elle ne doit donc pas être considérée comme l'intégralité de l'accueil.

### Objectif

Créer une première impression forte.

Le visiteur doit immédiatement comprendre :

> ACT’ERE agit pour un environnement plus durable.

---

## Image de fond

L'image doit représenter **les énergies renouvelables**.

Exemples :

* panneaux solaires ;
* éoliennes ;
* paysage naturel ;
* lumière solaire ;
* végétation ;
* infrastructure énergétique propre.

L'image doit être :

**photorealistic + premium + cinématique + environnementale.**

Éviter les images trop artificielles.

---

## Position du contenu

Contrairement à certaines variantes précédentes :

### Le texte doit rester à gauche.

Structure :

```text
—  Promouvoir les

ENERGIES

RENOUVELABLES

SENSIBILISER - AGIR - PRESERVER

[ Découvrir nos projets → ]
```

### Hiérarchie

**Promouvoir les**

petite taille.

**ENERGIES**

très grand.

**RENOUVELABLES**

très grand + vert.

Puis :

**SENSIBILISER - AGIR - PRESERVER**

Enfin :

**Découvrir nos projets →**

---

## Animation

Au chargement :

1. l'image apparaît progressivement ;
2. le petit texte apparaît ;
3. "ENERGIES" arrive légèrement par le bas ;
4. "RENOUVELABLES" apparaît ensuite ;
5. le slogan apparaît ;
6. le bouton apparaît en dernier.

Animation courte et élégante.

Pas d'animations excessives.

# 25. Règles importantes pour Antigravity

Voici les consignes que je mettrais **à la fin du prompt de développement** :

> **Ne pas modifier l'identité visuelle fournie.**
>
> Le Hero doit conserver la composition validée : image immersive en arrière-plan, navigation en haut, texte principal positionné sur la gauche, grande typographie blanche et verte, bouton d'action vert et indicateur de scroll.
>
> Le Hero constitue uniquement la première section de la page d'accueil. Il doit être suivi de plusieurs sections présentant l'ONG, ses actions, ses projets, son impact, l'éco-citoyenneté, son équipe et ses actualités.
>
> Conserver une direction artistique naturelle, premium, moderne et institutionnelle.
>
> Ne pas utiliser d'emojis dans l'interface.
>
> Éviter les termes techniques ou complexes dans les textes destinés aux visiteurs.
>
> Utiliser des micro-interactions modernes mais discrètes.
>
> Toutes les sections doivent avoir une cohérence visuelle avec le Hero.
>
> Le site doit être entièrement responsive.
>
> Les projets, articles, membres de l'équipe, statistiques et messages doivent être conçus pour fonctionner avec une base de données.
>
> Ne pas créer de fausses fonctionnalités simplement pour donner l'impression qu'elles existent.
>
> Le code doit être propre, organisé, maintenable et évolutif.
>
> Priorité absolue : **UX, lisibilité, performance et cohérence graphique.**
